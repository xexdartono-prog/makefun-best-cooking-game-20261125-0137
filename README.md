Ember Counter is a small original cooking game for the make.fun bounty
[Make the best cooking game](https://make.fun/bounty/best-cooking-game-20261125-0137).

Run a busy counter through short lunch shifts: read the order board, pick the
right ingredients from the shelf, assemble the dish, cook it before patience
runs out, and serve the finished plate. Mouse clicks and keyboard shortcuts
both work. The game is static files under `game/` and plays offline in a
desktop browser.

Hand-in check:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
